# ARVOSTA Sales

Myyntikäyttöliittymä (Next.js) ja Supabaseen perustuva CRM.

## Julkaisuperiaate

- `main` on suojattava tuotantohaara.
- v4-lähdekoodi ja esikatselujulkaisu valmistellaan erillisessä `preview/v4-sales`-haarassa.
- Tuotantoon ei siirretä ennen kirjautumisen, tarjouksen tallennuksen, numeroinnin ja PDF-latauksen hyväksyttyjä testejä.
- Testi ei saa luoda tilausta, laskua tai maksua.

Tämä alustava README ei sisällä sovelluksen lähdekoodia. Lähdekoodin siirron onnistuminen on varmennettava erikseen.
